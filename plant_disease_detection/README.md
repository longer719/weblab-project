# 植物种类识别与病害检测系统用户指南

## 系统概述

植物种类识别与病害检测系统是一款基于深度学习技术的智能工具，专为农业工作者、园艺爱好者和研究人员开发。系统能够识别上传图像中的植物种类，检测叶片上的病害，并提供相应的治疗建议。

**当前版本说明**：本系统基于PlantVillage数据集训练，仅支持该数据集中包含的14种植物及其相关病害。

## 使用指南

### 基本操作流程

1. **访问系统**：打开浏览器，访问系统首页
2. **上传图像**：点击"上传图像"按钮或将图片拖放到指定区域
3. **选择操作**：根据需要，选择"识别植物"或"检测病害"
4. **查看结果**：系统将显示识别/检测结果和相应建议

### 最佳实践

为获得最准确的结果，请注意以下几点：

1. **图像质量**：上传清晰、光线充足的图像
2. **叶片取样**：尽量拍摄单一植物的叶片，避免背景干扰
3. **病斑清晰**：如拍摄病害，确保病斑区域清晰可见
4. **多角度测试**：如结果不理想，可尝试不同角度的图像

### 结果解读

1. **植物识别结果**：显示识别出的植物种类及置信度
2. **病害检测结果**：
   - 边界框：标出病害区域位置
   - 热图：显示病害严重程度分布
   - 病害类型：显示检测到的病害名称
   - 置信度：表示识别准确度的数值

3. **治疗建议**：
   - 病害名称和症状描述
   - 推荐治疗方法
   - 预防措施

## 系统局限性

请注意以下系统局限性：

1. **支持范围有限**：仅支持PlantVillage数据集中包含的14种植物及其病害
2. **环境影响**：光线条件、背景干扰可能影响识别准确性
3. **非医疗诊断**：本系统提供的是参考性建议，不能替代专业植物病理学诊断

## 常见问题

1. **上传图像但没有响应？**
   检查图像格式(支持JPG、PNG)和大小(不超过10MB)

2. **识别结果不准确？**
   尝试更清晰、更聚焦的图像，或从不同角度拍摄

3. **没有显示治疗建议？**
   某些罕见病害可能尚未包含在我们的数据库中
